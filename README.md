# Reminder Application

This project is a web-based reminder application developed during my internship.

## Features

- Create and manage tasks
- Set task priorities
- Assign tasks to specific people
- Add notes to tasks
- Store task and note information in SQLite
- Notification and sound features
- Task status management

## Technologies

- HTML
- CSS
- JavaScript
- SQLite
- Node.js

## Development Environment

The project was developed using Visual Studio Code.
